# Pizzateig-Rechner

Angular app that calculates pizza dough (direct, poolish, biga) from number and weight of dough balls.
Yeast is derived from the fermentation schedule (time + temperature); the pizza diameter is estimated from the style.

## Requirements
- Node.js 22.12+ (Angular 21)

## Commands
```bash
npm install
npm start      # dev server on http://localhost:4200
npm test       # unit tests (Vitest)
npm run build  # production build
```
